# ELYSIUM — файлы для GitHub

## Структура пакета

```
├── index.html                    → замените корневой index.html в denisdefis1.github.io
├── fetch_report.py               → замените корневой fetch_report.py (2 бага починены)
├── .github/workflows/update.yml  → замените .github/workflows/update.yml
└── strategy/
    └── index.html                → НОВАЯ папка, новый файл — страница стратегии Google/Yandex/Meta
```

## Что делать

1. **index.html** (в корне) и **fetch_report.py** — замените существующие файлы этими. Внутри — оба фикса из переписки: язык теперь определяется по реальному формату `[RU]`/`[EN]` в квадратных скобках, а не по старому предположению через `_`; переключатели «цель» и «язык» больше не конфликтуют друг с другом (это и была причина `undefined` в шапке и того, что RU/EN/KA не работали); превью креативов теперь подтягиваются точечно по тем ad_id, что реально есть в отчёте, а не общим списком с обрезающим лимитом.

2. **.github/workflows/update.yml** — замените существующий, если менялся (здесь то же содержимое, но проверьте, что путь точно `.github/workflows/update.yml`, GitHub требует именно эту структуру папок для автозапуска).

3. **data/report.json** — **НЕ трогайте**, этого файла в пакете нет специально. У вас он уже содержит реальные данные из первого успешного запуска — если положить поверх мой пустой шаблон, вы на несколько часов (до следующего автозапуска) вернётесь к нулям на дашборде.

4. **strategy/index.html** — это новый файл, его раньше не было. Создайте в репозитории папку `strategy` и положите файл туда. Открываться будет по адресу `denisdefis1.github.io/strategy/`.

## После загрузки

- Дашборд (корень сайта) — теперь наверху есть ссылка **«← Стратегия»**, ведёт в `strategy/`
- Страница стратегии — кнопка **«Дашборд»** в шапке ведёт обратно на корень сайта
- Проверьте, что обе ссылки реально работают после публикации — сама структура папок при загрузке через веб-интерфейs GitHub (drag-and-drop) иногда сбивается, надёжнее через Git (`git add . && git commit && git push`) или через загрузку каждого файла в правильную папку по одному.

## Если что-то не открывается

Пришлите скриншот — но, скорее всего, дело будет в том, что файл положили не в ту папку (например, `strategy/index.html` оказался в корне вместо подпапки). Структура папок в GitHub — это не место для приблизительности, один неверный уровень вложенности — и ссылка ведёт в никуда.
